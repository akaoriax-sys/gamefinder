# GameFinder v4

このサイト本体はChatGPTが作成しました。

## 起動
フォルダ内で:

```bash
python -m http.server 8000
```

ブラウザで:

```text
http://localhost:8000/
```

## あなたが今後すること
基本的にはChatGPTへ指示するだけで大丈夫です。

例:
- 「Minecraftに似たゲームの記事を追加して」
- 「スマホゲームを10本追加して」
- 「もっと黒基調にして」
- 「ランキング機能を付けて」
- 「アフィリエイトリンクをこのURLに変更して」

## 注意
収益リンクは、各サービスで正式に提携・承認されたものだけを使ってください。
